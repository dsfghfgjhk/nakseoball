# 낙서볼

그린 대로 날아가는 3D 야구 게임. 브라우저에서 바로 실행된다 (Three.js 0.149).

## 플레이
- **투구**: 화면에 공이 날아갈 길을 그리면 그 궤적 그대로 공이 날아간다. 선 끝이 스트라이크 존 안이면 스트라이크.
- **타격**: CPU 투수의 마구를 타이밍 맞춰 터치해서 친다. 공 아래쪽을 치면 뜬공, 위쪽을 치면 땅볼.
- **레벨 1~5**: 동네 야구왕 → 야구부 주장 → 2군 거포 → 외국인 용병 → 괴물 신인
- **링크 대전**: 던진 공을 링크(`#nb.<코드>`)로 보내고, 친구가 치고 다시 던져서 보내는 방식으로 3회 진행.

## 실행
`index.html` 하나로 동작한다. GitHub Pages를 켜면 그 주소로 바로 플레이할 수 있다.
